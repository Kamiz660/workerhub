## Project Snapshot

We are building a frontend-only MVP marketplace for local contract workers.

Goal: Validate demand quickly.
Do not over-engineer anything.

---

## Core User Flow

1. User lands on site
2. Browses workers
3. Searches/filter workers
4. Opens profile
5. Contacts worker

No backend yet.

No auth yet.

No database yet.
